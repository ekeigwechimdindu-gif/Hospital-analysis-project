# Hospital-analysis-project
An end to end hospital data analysis project using excel, power bi and DAX to analyze hospital operations, finance and demographics through interactive dashboards.
## Project overview
This project analyzes hospital data using Excel, Power bi, and DAX to provide insights into hospital admissions, patient demographics, and billing performance. The dashboard helps the hospital management monitor operational efficiency, patient distribution, and financial performance.

---
## Tools used
Microsoft Excel
Power bi desktop
Power query
DAX

---
## Dataset
The dataset contains five hospital tables:
-Patients
-Admissions
-Doctors
-Wards
-Billing

---
Key Insights
-Elective admissions account for more than half of all hospital admissions.
-Cardiology records the highest average length of day.
-Urology has the highest number of admissions.
-The hospital collected over 83% of billed revenue.
-Male patients slightly outnumbered female patients.
-Patients aged 36-50 form the largest patient group.
